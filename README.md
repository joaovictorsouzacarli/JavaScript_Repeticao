# Laços de Repetição em JavaScript

Este diretório reúne uma série de exercícios práticos para estudar e reforçar o uso de laços de repetição em JavaScript, com foco principal no comando `for`.

## Objetivo

Praticar conceitos fundamentais como:

- contagem e iteração;
- uso de `for` para percorrer valores;
- verificação de números pares e ímpares;
- manipulação de strings e arrays;
- uso de acumuladores para somar valores;
- controle de fluxo com `if`, `break` e mensagens de alerta;
- criação de sequências numéricas e tabuada.

## Conteúdo abordado

Os exercícios foram organizados em ordem crescente de dificuldade e abrangem:

- contagem de 1 a 10;
- listagem de números pares;
- leitura de caracteres de uma palavra ou senha;
- comparação de valores e tentativa de acertos;
- soma de números em intervalos;
- tabuada;
- cálculo de idade ano a ano;
- regressiva para lançamento;
- uso de `break` para interromper a execução;
- simulação de economia acumulada ao longo dos dias.

## Como executar

A partir da pasta do projeto, rode qualquer arquivo com Node.js:

```bash
node 001.js
```

Ou qualquer outro arquivo, por exemplo:

```bash
node 009.js
```

## Dicas de estudo

- Comece lendo o código de cada exercício e tente prever a saída antes de executá-lo.
- Teste variações nos valores para entender melhor o comportamento do `for`.
- Experimente trocar `for` por `while` e compare a lógica entre os dois.
- Use `console.log()` para visualizar o fluxo do código e os valores em cada iteração.

## Observação

Este material é ideal para quem está começando em JavaScript e deseja reforçar a lógica de repetição na prática.
